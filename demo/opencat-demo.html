What OpenCat Does
🔍
Workspace Scanning
Parses Java, TS, JS files. Builds ASTs to identify controllers, services, repositories.
🧩
Feature Discovery
Traces dependencies from entry points through services to repositories. Groups into features.
🔀
Data Flow Tracking
Maps calls, imports, injections, events between components. Full request flow.
🤖
Copilot Integration
Sends rich context to GitHub Copilot. Automatic model fallback and retry.

Feature Browser

Context-Aware Chat
Conversation history, syntax highlighting, quick actions, inline copy.

Architecture
Component Detection & Dependencies
🏗️ Component Types
  • 🎮 Controller — HTTP/gRPC entry points
  • ⚙️ Service — Business logic
  • 🗄️ Repository — Data access
  • 📦 Model — Domain entities
  • ⚛️ Component / Hook — UI layer
  • 🔌 Middleware / Config — Cross-cutting
🔗 Dependency Tracking
  • 📥 import — Import/require statements
  • 💉 inject — @Autowired injection
  • 📞 call — Method/function calls
  • 🧬 extend — Class inheritance
  • 📋 implement — Interface impl
  • 📡 emit / subscribe — Events
